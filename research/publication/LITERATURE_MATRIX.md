# Literature Matrix

**Purpose.** One row per external source, recording exactly what it supports and — the column that matters more — exactly what it does **not** support. A source appears here only if its bibliographic record was verified against a publisher deposit, a DOI resolution, or the issuing institution's own page.

**Status:** Phase B. Built on `publication-package`. Gate A is frozen at `af2fc2d`; nothing in this file amends a Gate A document.

---

## 0. Rules this file was built under

1. **No invented citations.** Every title, author list, year, venue and DOI/URL below was checked. Where a record could not be fully verified, the row says so.
2. **Primary research and authoritative institutions only.** Peer-reviewed journals, working papers from NBER/BIS/IMF/World Bank, official regulatory and standards documents. **No blogs, no vendor or lender marketing.** An early search for "revenue-based financing" returned almost entirely lender marketing pages; all were discarded.
3. **This study remains Vietnam-*motivated*, not Vietnam-*calibrated*** (spec amendment A-8). No source below licenses a parameter value. Every parameter stays illustrative unless a source justifies **the exact value for the exact population**, and none does.
4. **Domain transfer is flagged, never assumed.** Most of the contingent-repayment literature is about student loans. That is a different borrower, a different obligation and a different legal regime. Rows say so.

### How to read a row

| Field | Meaning |
|---|---|
| **Supports** | The specific claim this source can carry. |
| **Does NOT support** | The adjacent claim it will be misread as carrying. This column exists because that misreading is the failure mode. |
| **Maps to** | Claim-ledger ID (`research/CLAIM_LEDGER.md`) or manuscript section. |

**The load-bearing observation for the paper.** Almost every source establishing that contingent repayment reduces borrower burden is about **students**, not firms. Almost every source about **firms** studies a different mechanism — deferral options (L-16), underwriting inputs (L-04, L-05), or observed behavioural responses (L-07). The head-to-head question this study addresses — how a revenue-contingent contract and a cost-matched fixed contract compare on *both* seller burden and provider recovery, under identical revenue paths — **does not appear to have been answered in the literature reviewed.** That is the contribution, and it is also why the study is a simulation: the data required to answer it empirically does not exist in public form.
