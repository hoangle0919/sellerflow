# ── Model-artifact stack — bounded, not floating (D-028) ─────────────────────
# `*.pkl` is gitignored and rebuilt at deploy time, so the artifact and the
# runtime that consumes it must agree. The previous `scikit-learn>=1.4.0` had no
# ceiling: a model built under one minor version could load under another and
# then raise at predict_proba, because estimator attributes change between
# minor releases. Upper bounds remove the silent-drift path; `ml_engine`
# smoke-tests the artifact at load and falls back to the deterministic heuristic
# if a mismatch still occurs.
#
# Supported interpreter: Python >= 3.11 (required by scikit-learn >= 1.8).
# See backend/ENVIRONMENT.md for what is verified and what is declared.
scikit-learn>=1.9.0,<1.10
numpy>=1.24.1,<3
pandas>=2.0.0,<3
joblib>=1.4.0,<2
